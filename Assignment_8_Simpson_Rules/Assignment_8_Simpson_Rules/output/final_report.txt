ASSIGNMENT 8 - SIMPSON 1/3 AND SIMPSON 3/8 RULES
=======================================================

Simpson 1/3 rule requires an even number of intervals.
Simpson 3/8 rule requires the number of intervals to be a multiple of 3.

Both Simpson rules have approximately fourth-order accuracy, O(h^4).

Question 1 uses f(x) = x^2 and exact value 2.666666666666667.
Question 2 uses f(x) = exp(-x^2) and reference value 0.746824132812427.

Question 3 Simpson 1/3 result = 6.3850000000
